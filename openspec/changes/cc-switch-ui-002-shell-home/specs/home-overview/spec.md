# Spec Delta

## Purpose

通过统一的桌面页面层级呈现首页概览，帮助用户查看现有账号数量、风险、用量和当前账号信息，并继续使用既有快捷操作；视觉简化只改变信息组织，不改变计算口径、阈值或跳转结果。

## ADDED Requirements

### Requirement: 概览与风险信息等价

首页 SHALL 按公共规范呈现账号统计、风险摘要和用量，保留原计算口径、阈值、精度、条件显示与超额提示；取消装饰性欢迎背景后，原内容仍可找到。

#### Scenario: 相同数据的风险概览
- **WHEN** 用户查看包含正常、封禁、即将过期和高用量账号的相同数据
- **THEN** 改版前后各指标数值、风险分组及条件提示一致，仅布局与外观变化

### Requirement: 首页操作和辅助内容保持

首页 SHALL 保留当前账号信息、全部原有快捷操作、风险跳转、版本与外链；没有账号或数据加载中的状态不能隐藏原有可用入口。

#### Scenario: 从首页进入原操作
- **WHEN** 用户点击风险入口、当前账号操作或任一原快捷入口
- **THEN** 原目标页面或业务动作被触发，参数及结果保持原行为，隐私模式沿用原掩码
