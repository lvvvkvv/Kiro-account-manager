# Spec Delta

## Purpose

为 KProxy 的服务和设备相关操作提供一致且可辨识的界面，使用户继续完成初始化、启停、配置、证书管理和请求状态查看，并保留现有系统权限、错误反馈与执行条件，避免外观调整触发额外系统操作。

## ADDED Requirements

### Requirement: KProxy 控制与状态保持

界面 SHALL 保留 KProxy 初始化、启停、现有配置、运行／错误状态和请求展示；布局重排和切页不能引入额外启动、停止或重复事件订阅。

#### Scenario: 查看运行中服务
- **WHEN** 用户启动 KProxy 后切换页面再返回
- **THEN** 按原生命周期显示服务和请求状态，未因页面呈现变化重复启动服务

### Requirement: 设备与证书操作保持

界面 SHALL 保留设备 ID 输入／生成／设置、CA 状态检查、导出、安装、卸载及原说明；权限提示、参数和结果沿用现有流程，不能以页面打开或配置重排自动执行系统操作。

#### Scenario: 导出或安装证书
- **WHEN** 用户明确执行原证书导出或安装操作
- **THEN** 调用原对应流程并显示原结果；未触发操作时不安装或卸载证书
