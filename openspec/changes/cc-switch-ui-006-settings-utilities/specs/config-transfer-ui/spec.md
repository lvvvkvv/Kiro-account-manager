# Spec Delta

## Purpose

为独立配置同步页的文件导入导出和注册偏好重置提供一致的选择、密码输入与结果反馈，使用户继续使用原类别、凭据选项和加密文件；界面调整保持实际支持字段、脱敏、合并方式和取消结果，不替换设置页的另一条同步路径。

## ADDED Requirements

### Requirement: 配置输出与导入兼容

独立配置同步页 SHALL 保留原类别、实际字段、版本、代理凭据包含选项、脱敏、导入校验和合并方式，默认不包含代理密码；不得借改版新增原文件未包含的存储键或账号凭据。

#### Scenario: 默认脱敏配置往返
- **WHEN** 用户沿原默认选项导出配置并重新导入
- **THEN** 文件字段、脱敏和导入计数遵循原规则，账号凭据不被额外加入，原不覆盖字段不因改版扩展

### Requirement: 加解密与取消保持

配置同步 SHALL 保留原密码加密、加密文件识别、解密输入及失败反馈，保持格式和密码处理；取消解密不导入，不能新增隐式降级为明文导入。

#### Scenario: 解密密码错误或取消
- **WHEN** 用户导入原加密文件时输入错误密码或取消
- **THEN** 显示原失败或取消结果，不应用配置；正确密码时按原流程导入

### Requirement: 注册偏好重置范围保持

配置同步 SHALL 保留注册偏好重置及原确认，实际移除的键与原实现一致，不扩大为全部应用重置或删除账号。

#### Scenario: 确认注册偏好重置
- **WHEN** 用户确认原注册偏好重置操作
- **THEN** 仅按原键集合移除相关偏好，账号数据保持，原刷新提示仍可见
