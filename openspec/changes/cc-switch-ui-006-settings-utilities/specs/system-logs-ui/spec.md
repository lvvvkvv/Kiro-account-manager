# Spec Delta

## Purpose

提供统一且适合高密度阅读的系统日志界面，使用户继续筛选、浏览和导出已有日志，并在追踪最新消息与阅读历史之间维持原滚动行为；视觉整理不改变日志来源、刷新机制、数量偏好或清理范围。

## ADDED Requirements

### Requirement: 过滤数量与详情保持

系统日志 SHALL 保留级别、分类、时间、文本筛选，数量选择与既有偏好、计数、明细展开及原刷新机制；相同输入得到相同结果集合。

#### Scenario: 多条件过滤
- **WHEN** 用户对相同日志选择级别、分类、时间和文本条件
- **THEN** 可见条目、计数及详情沿原规则，重新打开页面后数量偏好保持

### Requirement: 滚动导出与清理保持

系统日志 SHALL 保留底部自动跟随、离底部新消息计数、返回底部、按原范围导出和清理；不得将独立系统日志与反代明细日志的清理合并。

#### Scenario: 阅读历史时收到新日志
- **WHEN** 用户向上阅读历史并收到新条目
- **THEN** 原阅读位置按既有机制保持并显示新增提示；返回底部后恢复原跟随，导出内容遵循当前过滤规则
