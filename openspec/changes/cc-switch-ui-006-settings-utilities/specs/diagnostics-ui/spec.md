# Spec Delta

## Purpose

提供一致的诊断配置、进度和结果界面，使用户继续检查现有网络与服务连接、验证账号存活并导出报告，同时保留原复测和账号后处理操作；外观改变不扩大请求、删除或状态更新的目标范围。

## ADDED Requirements

### Requirement: 网络诊断保持

诊断页 SHALL 保留原诊断项目、自定义探针、代理选择、运行控制、进度、成功失败结果与报告导出，沿用原目标、超时和请求参数。

#### Scenario: 代理诊断失败
- **WHEN** 用户选择原代理与诊断项目后得到失败响应
- **THEN** 展示原诊断结果与原因，报告内容保持，不自动切换至其他目标或扩大诊断范围

### Requirement: 账号存活测试保持

诊断页 SHALL 保留单账号／选中批量、模型获取与输入、测试消息、原并发、停止、结果和失败复测，不因视觉选择控件改变目标账号集合。

#### Scenario: 停止选中批量测试
- **WHEN** 用户对选中账号运行存活测试后执行原停止操作
- **THEN** 按原停止边界处理并保留原已完成结果，未选中账号不受影响

### Requirement: 失败账号后处理保持

诊断页 SHALL 保留复测单条／失败项、标记失败账号错误及删除失败账号，保持原确认和取消语义，后处理不能与仅查看诊断结果自动绑定。

#### Scenario: 取消失败账号删除
- **WHEN** 用户查看失败结果后发起删除并取消原确认
- **THEN** 账号保持，诊断显示不触发额外删除；确认后的目标与原规则一致
