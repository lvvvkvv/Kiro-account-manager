# Spec Delta

## Purpose

提供统一的机器码和账号绑定管理界面，使用户继续读取、更改、备份、恢复设备标识并查看历史记录；视觉重排不改变系统写入、权限判断、配置联动或操作确认，维持既有设备与账号关系。

## ADDED Requirements

### Requirement: 机器码与系统操作保持

机器码页面 SHALL 保留读取／复制、随机／自定义更改、原始恢复、文件备份恢复、操作系统及管理员状态和原提权入口，保持原验证、确认与错误结果。

#### Scenario: 自定义更改失败
- **WHEN** 用户提交原不合法的自定义机器码或系统权限不足
- **THEN** 沿原规则阻止或返回失败，不因表单外观改变跳过校验或自动请求提权

### Requirement: 账号绑定与历史保持

机器码页面 SHALL 保留随账号切换、绑定／使用绑定码选项、账号搜索及绑定编辑／随机／删除，以及历史查看／复制／清理，保持原关联范围和持久化。

#### Scenario: 编辑绑定并取消
- **WHEN** 用户开始编辑某账号绑定后使用原取消操作
- **THEN** 原绑定保持，其他账号不被更改；确认保存后的历史与关联按原规则更新
