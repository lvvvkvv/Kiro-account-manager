# Spec Delta

## Purpose

为版本、项目信息、帮助外链和更新查询提供与全应用一致的关于页面，使用户继续找到现有辅助内容并辨认更新成功、失败与重试；页面外观改变不会替换现有更新服务或改变全局安装流程。

## ADDED Requirements

### Requirement: 关于内容与更新入口保持

关于页 SHALL 保留版本、项目与发布外链、二维码等原内容，以及更新查询、失败重试和对应结果；全局下载与安装继续沿原流程处理。

#### Scenario: 更新检查失败后重试
- **WHEN** 用户检查更新失败后点击原重试入口
- **THEN** 重新执行原查询并展示结果，项目外链和辅助内容仍可访问，未因新布局自动下载或安装
